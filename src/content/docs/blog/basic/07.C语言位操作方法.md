# C语言位操作方法

C 语言中常用位操作一般用于控制寄存器、状态标志、权限位、掩码等场景。位操作通常配合无符号整数类型使用，比如 `uint8_t`、`uint16_t`、`uint32_t`。

常用运算符：

| 运算符  | 含义   | 示例       |
| ---- | ---- | -------- |
| `&`  | 按位与  | `a & b`  |
| `\|` | 按位或  | `a \| b` |
| `^`  | 按位异或 | `a ^ b`  |
| `~`  | 按位取反 | `~a`     |
| `<<` | 左移   | `a << n` |
| `>>` | 右移   | `a >> n` |


## 设置某一位为 1

```c
value |= (1U << n);
```

例如设置第 3 位：

```c
value |= (1U << 3);
```

## 清除某一位为 0

```c
value &= ~(1U << n);
```

例如清除第 3 位：

```c
value &= ~(1U << 3);
```

## 翻转某一位

```c
value ^= (1U << n);
```

例如翻转第 3 位：

```c
value ^= (1U << 3);
```

## 判断某一位是否为 1

```c
if (value & (1U << n)) {
    /* 第 n 位为 1 */
}
```

例如判断第 3 位：

```c
if (value & (1U << 3)) {
    /* 第 3 位为 1 */
}
```

如果只想得到 0 或 1：

```c
bit = (value >> n) & 1U;
```

## 设置多位

可以先定义掩码：

```c
#define BIT0 (1U << 0)
#define BIT1 (1U << 1)
#define BIT2 (1U << 2)
```

同时设置第 0 位和第 2 位：

```c
value |= (BIT0 | BIT2);
```

同时清除第 0 位和第 2 位：

```c
value &= ~(BIT0 | BIT2);
```

## 提取某几位

例如提取**从第 `start` 位开始，长度为 `len` 的字段**：

```c
field = (value >> start) & ((1U << len) - 1U);
```

例如提取第 4 到第 7 位：

```c
field = (value >> 4) & 0x0FU;
```


**0x0f == (1U << 4) - 1U**

**(1U << len) -1** -- 多少个 1

## 修改某几位

先清除目标位，再写入新值：

```c
mask = ((1U << len) - 1U) << start;
value = (value & ~mask) | ((new_value << start) & mask);
```

例如修改第 4 到第 7 位：

```c
mask = 0x0FU << 4;
value = (value & ~mask) | ((new_value << 4) & mask);
```

## 注意事项

- 位编号通常从 0 开始。
- 操作位时优先使用无符号类型，避免有符号右移和溢出带来的不确定问题。
- `1U << n` 中的 `n` 不能大于或等于类型的位宽。
- 修改寄存器时，注意有些位可能是只读位、写 1 清除位或保留位。
- 表达式里建议加括号，避免运算符优先级导致结果不符合预期。
